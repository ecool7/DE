# Глоссарий (банк + данные)

| Термин | Простыми словами |
|--------|------------------|
| АБС | Автоматизированная банковская система — «источник правды» по счетам/клиентам |
| АПК | Агропромышленный комплекс — ключевой сегмент РСХБ |
| КФХ | Крестьянское (фермерское) хозяйство |
| DWH | Корпоративное хранилище данных |
| Staging | Промежуточный слой после сырых данных |
| Mart / витрина | Таблица «под отчёт», удобная бизнесу |
| Grain | Зерно факта: «одна строка = что?» |
| SCD2 | Хранение истории изменений измерения (valid_from / valid_to) |
| NPL | Non-Performing Loan — проблемный / просроченный кредит |
| Watermark | Метка «до куда уже загрузили» для инкремента |
| Идемпотентность | Повторный запуск даёт тот же результат |
| DQ | Data Quality — проверки качества данных |
| DAG | Граф задач в Airflow |
| Backfill | Пересчёт исторических дат |
| ПДн | Персональные данные |
| Стенд (test/prod) | Изолированная среда: test для разработки, prod для «боевых» данных |
| Релиз / promote | Перенос проверенного артефакта из test в prod |
| Ops Console | Учебная веб-панель, чтобы глазами смотреть стенды и логи |
