# Как работать с задачами (твоя «Jira»)

## Файлы

| Файл | Зачем |
|------|--------|
| `CURRENT_SPRINT.md` | Задачи текущей недели (как спринт в Jira) |
| `TASK_MANAGER.md` | Сюда пишешь: что сделал, что не вышло, вопросы |
| `BACKLOG.md` | Идеи / долги / «сделать потом» |
| `sprints/YYYY-Wxx.md` | Архив спринтов |
| `reviews/` | Сохранённые ревью от AI |

## Еженедельный ритм

### Понедельник — старт спринта

В чат Cursor напиши:

```text
Понедельник — выдай спринт
```

AI обновит `CURRENT_SPRINT.md` по roadmap + твоему прогрессу.

### В течение недели — берёшь задачу

1. В `CURRENT_SPRINT.md` статус → `In Progress`  
2. Делаешь работу в коде/SQL  
3. В `TASK_MANAGER.md` заполняешь блок «Сдал на ревью»  
4. В чат:

```text
Ревью моей работы
```

AI проверит код, напишет ревью в `TASK_MANAGER.md` и при желании в `reviews/`.

### Пятница — закрытие

1. Обнови статусы в спринте  
2. В `TASK_MANAGER.md` — краткий weekly summary  
3. Что не успел — в `BACKLOG.md` или перенос на след. спринт

## Статусы задач (как в Jira)

`To Do` → `In Progress` → `In Review` → `Done` / `Blocked`

## Типы задач

- **Story** — фича на несколько дней  
- **Task** — конкретная работа 1–3 часа  
- **Bug** — починить пайплайн / данные  
- **Spike** — исследование (макс 2–3 часа, итог = заметка)  
- **Chore** — рефактор, доки, уборка

## Правила для тебя

1. Не бери >1 Story в `In Progress` одновременно.  
2. Если застрял >40 минут — пиши в TASK_MANAGER блокер и зови AI.  
3. Done = есть код/SQL + коротко «как проверить» в TASK_MANAGER.  
4. Теорию гугли/спрашивай только под текущую задачу.
